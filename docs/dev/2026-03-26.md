## Bug 修复与功能实现

### 1. 佐伊·萨马拉斯交战选择机制

**问题**: 佐伊与敌人交战时，她的Reaction能力（获得1资源）和佐伊的十字架（花费1资源造成1伤害）都是自动触发，玩家无法选择。

**解决方案**: 实现统一的交互式选择机制

**修改文件**:
- `backend/cards/guardian/zoey_samaras.py`:
  - 重写 `gain_resource_on_engage` 方法
  - 现在会在交战时设置 `pending_choice` 而不是自动触发
  - 检查十字架是否可用（在场上、未横置、有1资源）
  - 根据可用选项动态生成选择列表

- `backend/cards/neutral/zoeys_cross_lv0.py`:
  - 移除独立的 @on_event 处理器
  - 说明：该卡的Reaction现在由佐伊的调查员能力统一处理

- `server/game_session.py`:
  - 在 `_resolve_choice` 中添加 `"zoey_reactions_on_engage"` 处理逻辑
  - 支持选项："resource"（获得1资源）、"cross"（使用十字架）、"both"（两者都触发）、"none"（都不触发）

**选择选项逻辑**:
```python
if cross_usable:
    options = [
        {"id": "resource", "label": "获得1资源"},
        {"id": "cross", "label": "使用佐伊的十字架（花费1资源造成1伤害）"},
        {"id": "both", "label": "获得1资源 + 使用十字架（花费1资源造成1伤害）"},
        {"id": "none", "label": "不触发任何能力"},
    ]
else:
    options = [
        {"id": "resource", "label": "获得1资源"},
        {"id": "none", "label": "不触发任何能力"},
    ]
```

**状态**: ✅ 已完成
