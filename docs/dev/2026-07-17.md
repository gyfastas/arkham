# 2026-07-17 开发日志

## 内容扩展：敦威治遗产全量实现

### 1. 关键基础设施修复（3 个"从未接线"的问题）

**问题 1：调查员能力在真实游戏中从未激活**
- 原因：`ZoeySamaras`/`DaisyWalker` 实现只在测试里手动注册，生产流程（`server/game_session.py` → `Game`）从未调用 `activate_card` 激活调查员实现
- 修复：`backend/engine/game.py` 的 `setup()` 现在自动激活以调查员 card_id 注册的实现（instance_id 为 `investigator_{inv_id}`）
- 测试：`backend/tests/test_investigator_activation.py`（3 个测试）

**问题 2：弱点卡抽到时不触发 revelation**
- 原因：`CARD_DRAWN` 事件发出时，被抽卡牌的实现并未注册在事件总线上（只有"打出"才激活）
- 修复：新增 `backend/engine/draw_hooks.py`——抽牌时临时激活卡牌实现再发事件；成为持续存在的卡（威胁区/场上）保持注册，否则注销
- 接线：`actions.py::_draw` 与 `phase_upkeep.py::_draw_and_resource`（UpkeepPhase 新增可选 card_registry 参数）

**问题 3：技能检定结果无法被卡牌效果翻转**
- 修复：`skill_test.py::_st6_determine_result` 现在回读 `ctx.success`（雷克斯的诅咒需要）
- 配套：`CardImplementation.persistent_in_hand` 标记（黑暗记忆留在手牌中持续生效）
